# Веб-админка — карта и машина времени (WEB2)

Read-only веб-интерфейс администратора, оформлен как **нативный плагин** (`plugins/webadmin`,
уровень N).

- Задача очереди: **WEB2** — `docs/tasks/QUEUE-WEB-admin.md`.
- Зависит от **PA2** (read-only History API) и **WEB1** (HTTP-сервер + вход); ни одна ещё не
  влита в `main`, поэтому этот этап отдаёт карту и машину времени самодостаточными модулями со
  своим минимальным сервером. См. `docs/tasks/WEB2-notes.md` и `KNOWN_ISSUES §A20`.

## Что делает

| часть | что |
|---|---|
| **Карта** | Тайлы сверху вниз: самый верхний непустой блок каждой колонки, с цветом и затенением по высоте. Тайлы кэшируются по `(zoom, tx, tz)` и **перерисовываются на изменении** — правка блока сбрасывает все тайлы, накрывающие колонку. Зум — `2^zoom` блоков на пиксель. Игроки/сущности — отдельный слой. |
| **Ползунок времени** | Перематывает журнал: `/tile_at?…&at=<seq>` рисует мир **каким он был** в любом прошлом номере события, проигрывая журнал поверх базовой генерации. `/history?x=&y=&z=` — полная история блока; `/changes?x=&z=&r=` — изменения области за окно времени. |
| **История игрока** | `/player?id=<uuid>` возвращает всё, что игрок поставил, сломал, взял или положил, с фильтром по времени и области; каждая строка несёт координаты для перехода на карте. |

Всё **только для чтения**. Ни один маршрут, функция или хук в этом крейте не пишет блок, предмет
или файл. Машина времени вычисляет прошлые состояния; она их не восстанавливает.

## Маршруты

Обычный HTTP/1.1, один JSON на запрос. Опциональный общий `?token=` (или `X-Token`).

| маршрут | что возвращает |
|---|---|
| `GET /` | страница карты (встроенные HTML + JS, без CDN) |
| `GET /app.js` | скрипт страницы |
| `GET /info` | `{tile_px, max_zoom, y_min, y_max, head}` |
| `GET /head` | `{head}` — номер события «сейчас» |
| `GET /tile?zoom&tx&tz` | сырой RGBA-тайл (блоб; заголовок `X-Tile-Px`) |
| `GET /tile_at?zoom&tx&tz&at` | тот же тайл, проигранный на событии `at` |
| `GET /surface?x&z[&at]` | `{x,z,y,id,name,water}` — верхний блок колонки |
| `GET /history?x&y&z` | все изменения одного блока, от старых |
| `GET /changes?x&z&r[&since&until]` | изменения блоков в радиусе за окно времени |
| `GET /player?id=<uuid>[&since&until&x&z&r&limit]` | действия одного игрока |
| `GET /overlay` | метки игроков/сущностей (пусто, пока WEB1 их не даёт) |

## Модули

| модуль | роль |
|---|---|
| `color` | имя блока → RGB (палитра офлайн-примера `vanilla_map`) со стабильным фолбэком |
| `source` | `MapSource` / `HistorySource` — два read-only представления мира, с impl для `aether_api::World` |
| `map` | рендер тайлов, кэш, инвалидация |
| `timemachine` | проигрывание журнала: история блока, изменения области, тайлы «как было» |
| `playerhist` | запросы по игроку и человекочитаемые сводки |
| `http` | встроенный сервер и страница |

Чистые модули не зависят от хоста плагинов, поэтому тестируются на моке и обычном `World`; обёртка
плагина (`WebAdminPlugin`) тонкая и владеет только жизненным циклом сервера.

## Подключение (когда появится WEB1)

```rust
let world = Arc::new(world);                     // aether_api::World
let admin = WebAdmin::with_config(world.clone(), world, cfg);   // один Arc, два представления
let plugin = WebAdminPlugin::new(admin, "127.0.0.1:8090");
// нативный реестр сервера добавляет `plugin` через PluginHost::add_native
```

До этого `WebAdmin::serve(addr)` запускает сервер напрямую (так делают тесты).

## Конфиг

`WebAdminConfig`: `tile_px` (по умолчанию 128), `y_min`/`y_max` (по умолчанию −64…319),
опциональный `token` и `history_limit`. Плагин читает `bind` из своей секции `[plugins.webadmin]`.

## Тесты

`cargo-locked test -p aether-webadmin-plugin` — 27 юнит-тестов (палитра, рендер/инвалидация
тайлов, зум, проигрывание, история, маршруты, токен, живой TCP-запрос) плюс 3 end-to-end теста на
настоящем `World`.
